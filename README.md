# MILO ✦

A zero-friction study tracker built by a student, for students.

**Live app:** https://rootspacestudios.github.io/milo/

## What it does
- Type `Maths: eigenvalues intro` to log a topic
- Type `Physics: lab report due next friday` to add a deadline
- Sticky note for upcoming dues, with overdue warnings
- Discussion slate by day, week or custom range
- Spaced revision reminders and fill-in-the-blank quizzes
- Optional in-browser AI for study doubts, with no API key

## Privacy
Everything is stored on your own device. No accounts, no servers.
Use the Backup button to move your data between devices.
